
# Large-Scale Personalized Recommendation Engine

A two-stage personalized recommendation system that retrieves relevant
items efficiently and ranks them to generate personalized recommendations.

## Project Goals

- Build a popularity-based baseline recommender.
- Implement candidate retrieval using a Two-Tower model.
- Use FAISS for efficient vector similarity search.
- Build a ranking model and evaluate recommendation quality.
- Serve recommendations through a FastAPI backend.
- Develop a React frontend for interactive demonstrations.
- Evaluate models using Recall@K and NDCG@K.

## Planned Technology Stack

- Python
- Pandas and PySpark
- TensorFlow Recommenders
- FAISS
- FastAPI
- React and Vite
- Redis
- Docker

## Dataset

MovieLens 25M is the planned dataset.
